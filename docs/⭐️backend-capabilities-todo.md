# 后端能力 TODO

## 目标

当前项目是本地可验收版本，宠物、金币、背包、好友、社交和在线中心都运行在浏览器本地。后端能力的目标，是把这些本地能力升级为可登录、可同步、可多人互动、可运营维护的生产服务。

## 阶段 1：账号与身份

- [ ] 设计用户账号模型：用户 id、昵称、头像、创建时间、状态。
- [ ] 设计登录方式：邮箱、第三方登录或匿名账号升级。
- [ ] 设计会话机制：access token、refresh token、过期策略。
- [ ] 设计设备绑定：同一账号多设备登录与退出。
- [ ] 设计基础安全策略：密码/令牌存储、CSRF/CORS、请求签名或防重放。

## 阶段 2：云存档

- [ ] 设计云端存档 schema，对齐当前 `SaveDataV3`。
- [ ] 实现上传存档：宠物状态、金币、背包、任务、花园、设置、资料。
- [ ] 实现下载存档：新设备恢复、刷新恢复、异常恢复。
- [ ] 实现冲突处理：本地较新、云端较新、双端同时修改。
- [ ] 实现存档版本迁移：后端兼容旧 schema，返回最新 schema。
- [ ] 实现损坏存档保护：拒绝非法结构，保留最近可用备份。

## 阶段 3：在线宠物中心

- [ ] 设计在线宠物资料接口：公开资料、阶段、心情、装饰、更新时间。
- [ ] 实现随机宠物列表：分页、刷新、过滤不可见账号。
- [ ] 实现好友宠物列表：只返回好友或允许公开展示的宠物。
- [ ] 实现宠物互动：问候、访问、送餐等轻量动作。
- [ ] 实现互动记录：对方可看到最近谁互动过。
- [ ] 实现限流：防刷互动、防刷奖励、防接口滥用。

## 阶段 4：好友系统

- [ ] 设计好友码：生成、重置、过期或长期有效策略。
- [ ] 实现添加好友：好友码添加、重复添加处理、自己添加自己拦截。
- [ ] 实现好友列表：昵称、宠物摘要、最近在线时间。
- [ ] 实现删除好友。
- [ ] 实现拉黑/屏蔽。
- [ ] 实现隐私设置：允许被搜索、允许被访问、允许互动。

## 阶段 5：社交动态

- [ ] 设计动态模型：作者、正文、宠物快照、创建时间、点赞数。
- [ ] 实现发布动态。
- [ ] 实现删除自己的动态。
- [ ] 实现动态列表：自己、好友、公开推荐。
- [ ] 实现点赞和取消点赞。
- [ ] 实现举报入口。
- [ ] 接入内容审核：昵称、正文、图片或未来资源。
- [ ] 设计违规处理：隐藏、下架、封禁、申诉。

## 阶段 6：经济与防作弊

- [ ] 后端校验金币变动来源：任务、活动、商店、花园、奖励。
- [ ] 设计交易流水：收入、支出、原因、时间、关联对象。
- [ ] 检测异常增长：短时间大量金币、重复领奖、篡改存档。
- [ ] 关键操作改为服务端裁决：购买、领取奖励、好友互动奖励。
- [ ] 设计回滚工具：误发奖励或作弊数据修正。

## 阶段 7：通知与运营

- [ ] 设计服务端提醒：饥饿、健康、活动结束、花园成熟。
- [ ] 接入 Web Push 或移动端推送。
- [ ] 设计用户通知偏好：开启、关闭、静默时段。
- [ ] 设计公告系统：版本更新、维护通知、活动提示。
- [ ] 设计灰度开关：按用户、比例或版本开启功能。

## 阶段 8：后台管理

- [ ] 用户查询：账号、宠物、存档、好友、动态。
- [ ] 存档查看与恢复：只读查看、备份恢复、风险标记。
- [ ] 内容审核后台：动态列表、举报处理、封禁操作。
- [ ] 运营配置：活动奖励、公告、功能开关。
- [ ] 数据导出：问题排查、客服处理、合规请求。

## 阶段 9：观测与稳定性

- [ ] 接入错误日志：API 错误、存档迁移失败、鉴权失败。
- [ ] 接入指标监控：请求量、延迟、错误率、活跃用户。
- [ ] 接入审计日志：登录、存档覆盖、金币变动、管理后台操作。
- [ ] 设计备份策略：数据库备份、对象存储备份、恢复演练。
- [ ] 设计降级策略：后端不可用时允许本地离线游玩。

## 阶段 10：接口边界

- [ ] 保持前端 `mockOnlineApi` 的接口边界，后续替换为真实 API adapter。
- [ ] 所有真实 endpoint 使用目标项目自有路径，不复用外部项目 endpoint。
- [ ] 所有请求和响应使用目标项目 schema，不接受 Tamaweb 原始存档格式。
- [ ] 保留本地 fallback：网络失败时不阻断基础照护闭环。

## 暂不做

- [ ] 暂不接真实 Hubchi 或第三方 Tamaweb 服务。
- [ ] 暂不做生产级 mod 平台。
- [ ] 暂不执行玩家上传脚本。
- [ ] 暂不加载玩家上传的远程资源。
