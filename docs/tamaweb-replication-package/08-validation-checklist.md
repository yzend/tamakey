# 08-validation-checklist.md

## 1. 功能验收清单

| 项       | 验收                                    |
| -------- | --------------------------------------- |
| 首次进入 | 无存档显示 egg，不直接显示 baby         |
| 孵化     | egg 自动转 baby，controls 解锁          |
| 主菜单   | 8 个入口可打开，返回栈正确              |
| 基础照料 | feed/sleep/bath/toilet 可用             |
| 需求推进 | 前台和离线推进一致可解释                |
| 成长     | 手动/自动生日可控，结果持久             |
| 死亡     | neglect 后进入 dead，新 egg/revive 正确 |
| 存档     | 自动保存、导入、导出、恢复              |
| 活动     | activity lock 生效，结束回 Home         |
| Garden   | plant/water/harvest 生命周期可用        |
| Missions | 任务完成、领奖、刷新                    |
| Settings | gameplay/system 设置保存                |

## 2. 合规验收清单

| 项       | 验收                                          |
| -------- | --------------------------------------------- |
| 源码     | 无 Tamaweb 函数体复制                         |
| 素材     | 无 Tamaweb 图片、声音、字体、logo             |
| 文案     | 无专有大段文案复制                            |
| 数值表   | 无原 growth/food/task/item 表复制             |
| endpoint | 无 Google Apps Script endpoint                |
| 品牌     | 不使用 Tamaweb 名称/logo/官方链接作为目标品牌 |
| 归因     | 如提及参考，使用 clean-room 归因措辞          |
| 许可证   | 不把 CC BY-NC-SA 资产混入目标商业代码         |

## 3. 工程验收清单

| 项       | 验收                                   |
| -------- | -------------------------------------- |
| 类型检查 | `tsc` 通过                             |
| lint     | 无阻塞问题                             |
| 架构边界 | domain 不访问 DOM/Pixi/IndexedDB       |
| 状态流   | 所有状态变化通过 command/reducer       |
| 渲染     | Pixi 使用 render model，不直接改 store |
| 存档     | schemaVersion + migration              |
| 错误处理 | global error + activity recovery       |
| PWA      | 缓存不阻断游戏                         |

## 4. 测试验收清单

| 项       | 验收                       |
| -------- | -------------------------- |
| 单元测试 | P0 domain 覆盖             |
| 集成测试 | 初始化、存档、照料、成长   |
| E2E      | 首次 egg、hatch、care loop |
| 视觉测试 | egg/baby/dead 非空         |
| 回归测试 | 每次发布前跑 P0 清单       |

## 5. 文档验收清单

| 文档 | 验收                   |
| ---- | ---------------------- |
| 01   | 工程侦察完整           |
| 02   | 功能地图覆盖主要源文件 |
| 03   | P0/P1 有详细规格       |
| 04   | 伪代码搬运合规记录     |
| 05   | 目标架构可执行         |
| 06   | 实施计划分阶段         |
| 07   | 测试计划覆盖核心路径   |
| 08   | 验收清单明确           |
| 09   | 差异和延后项明确       |
| 10   | 交接说明可执行         |

## 6. 差异验收清单

| 差异              | 是否可接受               |
| ----------------- | ------------------------ |
| 不复用原素材      | 必须                     |
| 不复用原 endpoint | 必须                     |
| 目标数值不同      | 可接受，需原创和平衡测试 |
| Hubchi 延后       | 可接受，P3               |
| Mod 延后          | 可接受，P3               |
| 社交媒体延后      | 可接受，P3               |
| UI 外观不同       | 必须不同                 |
